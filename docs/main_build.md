## 2. 요금 모드

OpenAI는 같은 모델이라도 처리 등급에 따라 요금이 다르다.

| 등급 | 요금 | 속도 | 사용 |
|---|---|---|---|
| `fast` | 가격표의 약 2배 | 빠름 | 500통 시험 구축 (의도하지 않음) |
| `default` | 가격표 그대로 | 보통 | **본 구축과 앞으로의 실험** |
| `flex` | 가격표의 절반 | 느리고 가끔 거절됨 | 쓰지 않음 |

- 이 계정은 등급을 지정하지 않으면 `fast`로 처리된다. graphrag는 등급을 지정하지 않는다.
- 그래서 500통 시험 구축은 가격표의 약 2.1배가 청구됐다 (1차 4.19달러, 2차 2.33달러).
- `enron/settings.yaml`에 `service_tier: default`를 넣어 고쳤다. 본 구축의 LLM 호출 19,648회가 모두 `default`로 처리됐다.

`settings.yaml`의 이 설정을 지우면 다시 2배 요금이 된다.

## 4. 하반기를 추가하면

상반기 실제 값에 메일 수 비율(2.3배)을 곱한 예상값이다.

| 항목 | 상반기만 | 상반기 + 하반기 (예상) |
|---|---|---|
| 기간 | 2001년 1~6월 | 2001년 1~12월 |
| 메일 | 3,661통 | 8,431통 |
| 구축비 | 11.17달러 | 약 26달러 |
| 구축 시간 | 2시간 42분 | 약 6시간 |
| 질문 하나 | 약 0.25달러 | 약 0.6달러 |
| 질문 60회 | 약 15달러 | 약 35달러 |
| 합계 | 약 26달러 | 약 61달러 |

**나중에 추가해도 손해가 작다.**
상반기 메일에서 엔티티를 뽑은 결과는 캐시에 남아 다시 과금되지 않는다.
다시 내는 것은 그래프가 바뀌어 새로 써야 하는 요약과 보고서뿐이고, 약 4.7달러다.

**단, 실험을 시작하기 전에 정해야 한다.**
그래프가 바뀌면 커뮤니티가 달라져 이전 실험 결과와 비교할 수 없다.

## 5. 하반기를 넣으면 달라지는 점

| | 좋아지는 점 | 나빠지는 점 |
|---|---|---|
| 양 | 메일이 2.3배가 된다. 빅데이터 수업 주제에 더 맞다 | 비용과 시간도 2배 넘게 든다 |
| 추세 질문 | 1년 동안의 변화를 물을 수 있다 | |
| 주제 | 주제가 둘 이상이 되어 가지치기의 효과를 볼 수 있다 | "같은 사건의 반복"이라는 조건이 흐려질 수 있다 |

- 2001년 10~12월은 엔론이 파산으로 가는 시기다. 메일의 주제가 전력 위기에서 회사 위기 대응으로 옮겨 갈 것으로 예상한다. 데이터로 확인한 것은 아니다.
- 500통 시험에서는 모든 상자가 질문과 관련 있다고 나와, 가지치기가 뺄 것이 없었다. 주제가 섞이면 무관한 보고서가 생긴다.
