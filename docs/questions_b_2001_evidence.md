# B안 연간 평가 정답과 원문 근거 · 2001년

[질문지](questions_b_2001.md)의 채점용 자료다. 근거 번호는 아래 명령으로 생성한 연간 CSV의 **헤더 다음 첫 레코드를 1번**으로 센 번호다. 한 메일 본문이 여러 줄일 수 있다. GraphRAG가 인용한 근거는 답변에 적힌 커뮤니티 보고서 ID로 확인한다.

**평가 범위.** 두 실험 조건에 같은 인덱스·커뮤니티 층·질문·정답 기준을 사용한다. 정답은 연간 원문에서 확인했다. 일부를 표본 추출해 인덱싱할 때는 질문이 지정한 비교 대상과 필요한 원문이 표본에 포함되는지 확인한다.

**채점 기준.** 상위형은 순서와 동률을 확인하고, 질문에서 요구한 값·단위·조건도 평가한다. 전수형은 필수 항목 누락과 범위 밖 항목 추가를 각각 기록한다. 추세형은 시기별 사실과 변화 방향을 확인한다. 초안이나 전망의 상태는 당시 근거에 맞게 밝혀야 한다. 표의 설명 중 질문이 요구하는 내용을 채점 대상으로 삼는다. 같은 대상을 가리키는 약칭과 정식 명칭, 의미가 같은 표현을 인정한다. 단위나 반올림을 요구한 문항은 지정한 형식을 적용한다.

**보고서 근거 확인.** 답변의 정확도와 인용이 근거를 뒷받침하는지를 각각 채점한다. 가지치기 전후 모두에서 정답에 필요한 사실이 어느 보고서에 남아 있는지와 실제 검색에 포함됐는지를 기록한다. 가지치기 전에 검색된 근거가 가지치기 후 빠진 경우를 찾으려면 두 결과의 보고서 ID를 대조한다.

## 입력 데이터 재현

저장소 루트에 원본 `emails.csv`가 있을 때 다음 명령을 실행하면 네 메일함의 상반기 3,661통과 하반기 4,770통을 얻는다.

```bash
python3 preprocess.py --src emails.csv --out data/b_2001/emails.csv \
  --mailboxes dasovich-j kean-s shapiro-r steffes-j --start 2001-01-01 --end 2002-01-01
```

출력 `data/b_2001/emails.csv`의 SHA-256은 `afb34347ba1faf96422ecdf01956403c984c794d69dcec07b99d91604a3c088b`이다.
